# Payment API Documentation

## Overview

This project is a sample API documentation project created to demonstrate
technical writing and API documentation skills.

The documentation explains how developers can integrate a payment API
into their applications.

## What this project covers

- API overview
- Authentication
- Create Payment API
- Get Payment API
- Payment status
- Error handling
- Webhooks
- JSON request and response examples
- OpenAPI specification

## API Features

| Feature | Description |
|---|---|
| Create Payment | Create a new payment transaction |
| Get Payment | Retrieve payment details |
| Payment Status | Check the current payment status |
| Refund | Request a payment refund |
| Webhooks | Receive payment event notifications |

## Technologies

- REST API
- JSON
- Markdown
- GitHub
- OpenAPI / Swagger
- Postman
